### ৩. ডাক্তার ও চেম্বার সহকারীর মোবাইল ভেরিফিকেশন অ্যাপ (`/verify`)
- স্মার্টফোন ও ট্যাবলেটে ইনস্টলেবল PWA রেডি ভিউ।
- **রিয়েল-টাইম লাইভ কিউ**: অপেক্ষমাণ পেমেন্ট, অনুমোদিত রোগী ও সংগৃহীত মোট ফির লাইভ কাউন্টার।
- **নতুন বুকিং আসলে অডিও অ্যালার্ট (Sound Chime)** বেজে ওঠে।
- **১-ট্যাপ অনুমোদন (Approve) ও বাতিল (Reject)** বাটন।
- **সরাসরি রোগীকে কল ও হোয়াটসঅ্যাপ করার শর্টকাট**।
- **স্বয়ংক্রিয় SMS ম্যাচিং টুল (Auto-Match SMS)**:
  - ডাক্তারের মোবাইলে আসা বিকাশ/নগদের SMS কপি করে পেস্ট করলেই সিস্টেম TrxID, টাকা ও প্রেরকের নম্বর স্বয়ংক্রিয়ভাবে বের করে সংশ্লিষ্ট রোগীকে ভেরিফাই করে দেয়।

## 🚀 লোকাল মেশিনে চালানোর নিয়মাবলী

### ১. ব্যাকএন্ড চালু করা (Port 5000):
```bash
cd backend
npm install
npm start
```
- ব্যাকএন্ড হেলথচেক: `http://localhost:5000/health`
- এপিআই রুট: `http://localhost:5000/api/appointments`

### ২. ফ্রন্টএন্ড চালু করা (Port 3000):
```bash
cd frontend
npm install
npm run dev
```
- মূল ওয়েবসাইট ও পেমেন্ট ফর্ম: **`http://localhost:3000`**
- ডাক্তারের মোবাইল ভেরিফিকেশন অ্যাপ: **`http://localhost:3000/verify`**
- ৬৪ জেলা সেবা তালিকা: **`http://localhost:3000/districts`**
- জেলা পেজের উদাহরণ: **`http://localhost:3000/zilla/dhaka`**

## ☁️ ক্লাউডে ডিপ্লয়মেন্ট গাইড

### ক. ব্যাকএন্ড ডিপ্লয়মেন্ট (Render.com)
১. আপনার কোডবেস গিটহাবে (GitHub) পুশ করুন।
২. [Render.com](https://render.com)-এ লগইন করে **"New +" -> "Blueprint"** চাপুন এবং রিপোজিটরিটি সিলেক্ট করুন।
   - রিপোজিটরির `backend/render.yaml` ফাইলটি স্বয়ংক্রিয়ভাবে ডিটেক্ট হবে।
   - অথবা ম্যানুয়ালি **"Web Service"** তৈরি করে রুট ডিরেক্টরি দিন `backend`, Build Command: `npm install`, Start Command: `npm start`।
৩. Health Check Path দিন: `/health`।
৪. ডিপ্লয় হলে আপনি একটি ফ্রি লাইভ এপিআই ইউআরএল পাবেন (যেমন: `https://hasina-homeo-cure-api.onrender.com`)।

### খ. ফ্রন্টএন্ড ডিপ্লয়মেন্ট (Vercel / Render Static)
১. [Vercel.com](https://vercel.com)-এ গিয়ে **"Add New Project"** চাপুন।
২. Root Directory নির্বাচন করুন: `frontend`।
৩. Environment Variables-এ যুক্ত করুন:
   - `NEXT_PUBLIC_API_URL` = `https://your-backend.onrender.com`
৪. **"Deploy"** চাপুন। মাত্র ১ মিনিটের মধ্যে সাইটটি বিশ্বব্যাপী আল্ট্রাফাস্ট এজ নেটওয়ার্কে লাইভ হয়ে যাবে!
